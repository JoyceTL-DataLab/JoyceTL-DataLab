## Portfólio

### Análise de Dados de E-commerce — Olist

**[Ecommerce-Analise-Olist](https://github.com/JoyceTL-DataLab/Ecommerce-Analise-Olist)**

Projeto de análise de dados de e-commerce com foco em logística, atrasos de entrega e satisfação dos clientes.

- Construção de pipeline ETL e tratamento de dados.
- Modelagem e consultas SQL com PostgreSQL.
- Análise exploratória e estatística dos dados.
- Desenvolvimento de dashboard interativo no Power BI.
- Investigação de indicadores de desempenho logístico e experiência do cliente.
